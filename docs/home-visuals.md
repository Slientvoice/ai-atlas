# 首页图示与动效记录

图示版本：2026-09-19 · v0.33。

首页 AI 系统全景包含两个可切换视图，均由本项目的 HTML/CSS/SVG 实现，无需外部图片请求。

- **系统关系**：七个工程平面的相互关系，点击平面可阅读说明并前往蓝图。训练形成模型，推理运行模型，系统连接知识与工具；物理基座提供支撑，多模态与具身作为能力延伸。这不是一次在线请求必经的七步流程。
- **模型剖面**：分词 → 向量 → 因果注意力 → 前馈网络 → 下一词元预测，以及自回归循环。五个步骤可分别查看，移动端突出所选步骤。数值和切词均为教学示意，未运行真实模型；位置编码、归一化、残差路径等细节省略。

本次上线使用原创矢量图，没有复制第三方截图、嵌入站外可视化或引入其代码。此前检索过的素材可作为后续参考，使用前须按具体文件复核许可证、署名要求和维护状态。

维护入口：`src/portal/OverviewMap.tsx`、`ModelCutaway.tsx`、`home.css`。入口保留可访问名称；图示不是唯一导航方式，旁边始终提供三个主要页面入口。


## 字符粒子规则（v0.35.1）

首页改版后，字符画布只手动加入开场与阅读路线，导致其他同类模块缺失效果。本轮以 `GlassSurface` 统一浅色玻璃容器，避免新增模块时漏挂字符层。

| 区域 | 规则 |
| --- | --- |
| 开场、三个入口、阅读路线、合规观察、更新记录 | 每个模块一个局部字符画布，共用轨迹、点击扩散与衰减算法 |
| AI 系统全景（含模型剖面） | `motion="quiet"`，保留图示和控件的阅读空间 |
| 顶部导航、深色方法区、页脚、模块间隙 | 不挂载字符层 |
| 全页流体背景 | 只挂载一次，位于全部内容下方 |

粒子始终在内容下方、圆角范围内，不拦截点击。指针事件只监听画布所属模块；移出或取消指针时清除轨迹起点。全局流体仍保留原有响应。

减少动态偏好采用响应式监听：开启时清除字符与动画循环、流体绘制为静态；关闭时恢复。缩放后重新选择桌面 / 窄屏的网格与像素精度；减少动态状态下也重新绘制静态背景。

验证：生产构建浏览器中确认五个字符画布、一层流体、静态区域零字符画布；入口、合规和更新模块均可触发扩散，模型剖面切换与步骤按钮可用。390px 窄屏页面无横向溢出。通过本地临时测试页模拟媒体偏好变化，确认动画停止及恢复，静态背景可随窗口缩放重绘；该测试页位于忽略的构建目录，不随站点发布。
