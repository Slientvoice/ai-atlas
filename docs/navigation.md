# 全站导航规范

2026-09-19 · v0.33。

| 入口 | 统一行为 |
| --- | --- |
| 品牌标识、返回首页 | 永远链接到本项目根目录的 `index.html`；不依赖来源页 |
| 后退 | 返回当前标签页的上一条站内浏览记录，包含锚点历史；没有记录时禁用 |
| 前进 | 后退后可返回下一条站内记录；没有记录时禁用 |
| 全部页面 | 显示七个读者页面，标记当前页，提供回到页首 |
| 站内正文、卡片链接 | 当前标签页打开；保留原生 Ctrl/Cmd 点击、新标签页和复制链接功能 |
| 官方资料与外部范例 | 保留原有新标签页行为及 `noopener` 属性 |

后退/前进只遍历紧邻的本站记录，不把它们当成按目录排序的“上一章/下一章”。直接从书签或新标签打开子页时仍可返回首页。按钮最小高度 44px；窄屏分成两行，页面滚动时保留导航。

支持 Navigation API 的浏览器读取原生会话历史，刷新和浏览器自身后退后同步按钮状态。不支持该 API 时隐藏无法可靠判断的前进按钮，只在存在本站 referrer 时提供返回来源页，首页与目录仍可使用。来源页返回为普通链接导航，不伪造历史栈。

目录支持键盘 Enter 展开、Escape 收起并返回焦点，点击目录外也会收起。锚点停靠会避开固定导航；初始化与锚点变化时展开目标的折叠祖先，避免蓝图实验室初始化打断深链接落位。浏览器从缓存恢复页面时保留已有滚动位置。

页面名单、HTML 模板和行为统一在 `assets/site-navigation.mjs`。静态页通过模块脚本初始化；React 首页用 `SiteNavigation.tsx` 复用模板和初始化函数。样式来自 `assets/site-navigation.css`。

执行 `node scripts/sync-navigation.mjs` 更新静态页，重复运行不会增加重复导航。不要直接编辑 `atlas-navigation:start/end` 标记之间的生成代码。新增正式页面时修改共享 `pages` 数组，重新构建并检查。站内链接使用相对路径，兼容 GitHub Pages 子路径与本地预览。

`npm test` 检查历史边界及兼容路径；`npm run check:links` 检查八个发布页面的静态链接、资源与锚点。React 生成的链接、交互及视觉表现还需浏览器验证。
