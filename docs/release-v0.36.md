## 修订结果

- 入门九站明确云端 GPU 只是例子，去掉固定三秒、固定参数规模、全流程只流动整数等说法。
- 分词补充归一化与还原边界；输入 token 嵌入与检索文本嵌入分开；人工二维图不再称作真实投影。
- 因果注意力说明自身/历史可见，移除“解约”指向后续“条款”的示意连线；不把预设权重或注意力图当作理解和因果证明。
- 训练数据与后训练补充适用边界，不推定某合同未进入训练、不把所有模型写成统一的 RLHF 路线。
- 删除入门最终回答中未由展示原文支持的“费用不予退还”句子；输出保持与示意输入一致。
- RAG 标为可选应用结构，并说明检索在最终回答前组织；实验仅到拼装，不包含真实生成或生产权限。
- Agent 区分调用意图与宿主执行，补充授权、预算、停止条件与验收。
- 生成说明 KV 复用、token/字符/流式更新的区别；护栏说明误报、漏报与多层控制。
- 修正 SiLU 负区归零的错误：gate=-1、up=3 时输出约 -0.807；已有函数计算正确，本轮修正文案与可自查的反例。
- 删除采样参数的统一工业默认、贪心只适合唯一答案等绝对表述；明确格式约束与内容真实性不同。
- 法律观察去掉“部署地即法域”“隐式标识就是水印”等简化，条文查阅与场景法律审校分别标记。
- 索引地图同步相关概念纠错，不将 28 个索引节点都计为完成来源核验；移除蓝图引用中写死的谱系 v4。
