开放度阶梯 · 「开源」其实分五层

一个模型 = 权重（炼好的结果）+ 训练代码（怎么炼的）+ 数据（用什么炼的），三样可以分开给。业界说的「开源模型」九成只给了第一样——严格说叫「开放权重」。从上往下，越往下越封闭：

L4 全开放权重+代码+数据

从零可复刻。商业公司无一做到——训练数据永不公开，这本身就是合规信号：数据是最大法律风险所在。

（空缺——学术代表：AI2 OLMo、Pythia）
L3 方法透明权重+详尽报告/部分代码

不止给结果，还告诉你怎么炼的（方法大体可复现），但数据配方仍不公开。

DeepSeek（论文与代码开放度为商业旗舰中最高◉，故单列此层；权重许可为宽松 MIT）
L2 开放权重宽松许可（MIT / Apache）

权重可下载，商用几乎无束缚：改、卖、闭源衍生都行。

Qwen◉GLM◐Kimi（改良 MIT，附署名条款◐）gpt-oss（OpenAI 小分支◉）Grok-1（旧版◉）
L1 开放权重限制性许可

权重可下载、可私有化部署与微调，但许可证带条件：用途限制、超大用户另谈、地域排除等——许可证逐条审查是法务作业。

Llama（超大用户条款◉）混元（含地域排除条款◐）Gemma（Google 小分支，自订许可◉）
L0 完全封闭仅 API 租用

模型是黑盒，数据进它机房；能不能用、怎么用，全看服务条款。

⚖ 朱批 · 选型即合规决策（AI 起草，待用户法律审校）
  1. 开放度阶梯即尽调地图：L0 看服务条款与数据出境，L1 逐条审许可证（用途/规模/地域条款），L2 之后重心转向输出侧责任与安全评估——层级不同，法务作业清单不同。
  2. 境内备案状态决定能否面向公众提供服务（生成式 AI 管理暂行办法的备案要求）；美系模型的境内使用需另行设计合规路径。
  3. 美系模型双向审视：既看数据跨境与内容合规，也要注意出口管制条线的反向波及。
  4. 「数据姿态」是供应商风险信号源：训练数据诉讼与和解直接映射到侵权连带与合同保证条款的谈判点。
