▶语料池与配比CORPUS · DATA MIX · 🔬 LAB原始文本 ~10¹³ token 级

预训练的输入是数以十万亿计的 token：网络爬取（占大头）、书籍、论文、代码、多语文本。配比是产品决策：代码占比抬推理能力，多语占比决定语种表现——模型的能力版图在开跑前就由配方锁定了。Llama-3 训练量约 15T token，作为量感参照：一个人一生的阅读量约 10 亿 token 上下，差四个数量级。

  • 高质量语料（书、论文、代码）稀缺且最先耗尽——这是「合成数据」路线兴起的直接原因。
  • 数据配比各家保密，属于核心资产；公开的多是总量与来源类别。
🔬 实验室 · 配方即能力G2 级

原始文本 ▼
▶清洗 · 去重 · 过滤CLEANING PIPELINE · 🔬 LABTB 原始 → 高质量 token 流

工业级流水线：正文提取（去导航去广告）→ 去重（URL 级 + MinHash 近似去重，重复文本会让模型死记硬背并浪费算力）→ 质量过滤 → 安全过滤 → PII 检测移除。

分叉 · 质量过滤怎么做
按符号密度、长度、语言 ID、黑名单域名等硬规则筛。便宜、可解释，但误杀多样性（方言、少数表达易被错杀）。早期管线的主体。
训练一个小分类器给每篇文档打「质量分」（常以教科书/百科风格为正样本），按分数取舍或加权采样。现代管线主流，与规则法叠加使用。过滤器的品味 = 模型的品味，这一步已经在塑造价值观。

干净文本 ▼
▶分词器训练TOKENIZER TRAINING · 🔬 LAB语料统计 → 词表 V ≈ 32k–256k

在模型训练之前，先从语料统计出一部「切词法典」。它一旦定稿终身不改——模型看世界的颗粒度就此固定。词表大小 V 是第一个超参权衡：V 大 → 单 token 携带信息多、序列变短省算力，但 Embedding/LM Head 参数变大、稀有 token 训不充分。

分叉 · 算法
Byte-Pair Encoding：从单字节起步，反复合并语料中最高频的相邻对，合并表即词表。任何字符串都可编码（未知词退化为字节），无 OOV 问题。GPT 系、Llama-3（tiktoken 风格，V=128k）均用。
Unigram 语言模型法：先给一个大候选词表，迭代删除对似然损害最小的词。SentencePiece 实现，早期 Llama/T5 使用。与 BPE 效果接近，路线之争已基本收敛于字节级 BPE。
不学合并、直接按字符或字节切：序列被拉长数倍、算力代价大，仅研究性架构使用。反向说明了为什么需要「子词」这个中间粒度。

中文注记：同样内容中文通常比英文更费 token（词表以英文为主时尤甚）——计费与上下文长度的隐性不平等，法务审 API 合同时可留意。

▶预训练循环PRE-TRAINING LOOP · 🔬 LAB[B,T] → loss（标量）→ 梯度 → 权重

整个平面的心脏，一个四拍循环，重复数百万步：

前向: logits = Model(tokens[B,T]) # 每个位置预测下一 token 的分布 损失: L = −log p(真实下一token) # 交叉熵，对全批取平均 反向: ∂L/∂θ # 每个参数对本次错误的「责任份额」 更新: θ ← θ − lr · AdamW(∂L/∂θ) # 沿责任方向微调所有参数

损失曲线是唯一的仪表盘：它随 数据 × 参数 × 算力 按幂律可预测地下降（Scaling Laws），这是「大力出奇迹」的数学依据。Chinchilla 法则给出配比经验：算力最优时训练 token 数 ≈ 参数量 × 20。

展开：工程细节（学习率调度 / 显存账 / 容灾）

· 学习率不恒定：先 warmup 爬升再余弦衰减；梯度裁剪防爆炸。
· 显存经验法则：混合精度训练每参数约 16 字节（权重 2 + 梯度 2 + fp32 主副本 4 + Adam 动量 4 + 方差 4）——8B 模型仅训练态就 ≈128GB，必须多卡并行（详见索引地图 L0「集群与并行」）。
· 一跑数月，硬件天天坏：按小时存 checkpoint，坏了回滚续跑。中途发现数据配比错了？不可逆，只能认。

分叉 · 训练目标
只预测「下一个 token」。生成天然顺手，GPT 系确立、当今几乎唯一主流。简单到令人不安——全部智能都从这一个游戏里涌现。
随机遮住句中若干词让模型填空（BERT 时代，2018–2021 主流）。理解任务强但不会生成，已退出大模型主战场——一次完整的路线兴衰，值得作为案例研究。
一次预测未来多个 token（DeepSeek-V3 采用 MTP）：训练信号更密、还能给推理加速当草稿。前沿改良，非主流默认。

会对话的模型 ▼
▶偏好优化PREFERENCE OPTIMIZATION · 🔬 LAB偏好对（A优于B）→ 价值观入参

SFT 教会格式，这一步教会「分寸」。原料统一是偏好对：同一提问的两个回答，人类标注哪个更好。分歧在于怎么把偏好变成梯度：

分叉 · 优化路线
两段式：先用偏好对训练一个「奖励模型」（学会人类品味的打分器），再用强化学习（PPO）让主模型在打分器上刷高分。ChatGPT 立身之法。缺点：贵、不稳、会被「钻空子」——模型学会讨好打分器而非真正变好（reward hacking，AI 谄媚的技术根源）。
Direct Preference Optimization：数学上证明可以跳过奖励模型，把偏好对直接写进一个闭式损失函数。一段式、稳定、便宜，开源社区主流。代价是失去了可复用的独立打分器。
组相对策略优化：对同一题采样一组回答、按组内相对好坏给信号，配合「可自动判分的任务」（数学/代码）使用——DeepSeek-R1 推理能力的训练方法。前沿：把「人类偏好」换成了「可验证的对错」。

扩建 · 评估科学：为什么 benchmark 数字要打折看（v0.9）

基准的三大陷阱：① 污染——题目或其变体泄入训练集，分数测的是「背过」而非「会做」；② Goodhart 定律——一旦榜单成为目标，刷榜技巧就与真实好用脱钩（针对性微调可专门抬分）；③ 饱和——顶级模型分数挤在天花板附近，区分度失效，榜单只好不断换新题。
LLM 当判官（LLM-as-judge）：用强模型给模型输出打分——便宜、可规模化，已是行业标配；但判官自身有系统性偏差：偏爱与自己风格相近的回答、偏爱更长的回答、受选项位置影响——「判官的判官」是未解的套娃问题。
实务启示（写给法务）：读任何「模型跑分」宣传先问三件事：题集多老、是否可能被污染、谁判的分。采购与备案材料中引用评测结果时，注明评测集与评测方是基本卫生。

分叉
旋转位置编码：把 Q、K 向量按维度两两配对，每对视作平面上一点、按「位置 × 各对不同的角速度」旋转。妙处：两个被旋转向量的点积只依赖相对位置差——相对性自然涌现。当今几乎所有开源主流（Llama、Qwen、DeepSeek）标配；长上下文外推的各种改造（NTK 缩放、YaRN）都在改它的角速度表。

全模型 = 同一种积木摞 N 层。理解一层就理解了全部。一层内部两个子单元，各配一次归一化和一条残差连接：

残差流是关键意象：一条贯穿全部 N 层的「传送带」（宽度 d），每个子单元只是从带上读取信息、加工后加回带上——而不是整体变换。这保证了梯度能穿透几十层（深度网络可训练的前提），也是可解释性研究读写模型「思想」的界面。

🔬 实验室 · 残差流：信息为什么能穿过 32 层G3 级

同一个信号向量，走 32 层随机变换：一条路有残差（每层只往传送带上「加一点」），一条路没有（每层整体变换）。曲线 = 各层输出与原始信号的相似度，实时计算。

实线 = 有残差（x ← x + 0.1·f(x)），虚线 = 无残差（x ← f(x)）。纵轴：与第 0 层信号的余弦相似度。
诚实标注（R5）：迭代与相似度为实算；f 为固定随机线性变换（真实模型的 f 是训练出来的注意力与 FFN）。现象本身是深度学习的真定理级经验：无残差时原始信息几层内被搅碎，有残差时穿透几十层仍在——这就是 2015 年残差连接让「深」网络成为可能的原因，也是「残差流 = 贯穿全程的传送带」这个意象的数学根据。

▶注意力ATTENTION · 🔬 LAB[B,T,d] → [B,T,d]　中间量 [B,h,T,T]

整摞模型中唯一让 token 之间交换信息的地方（其余模块都是每个位置各算各的）。每个位置对此前所有位置计算相关度，按权重汇聚信息。核心式：

Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V
展开：Q / K / V 从哪来、mask 怎么加、多头是什么

· 同一输入 X 乘三个学出来的投影矩阵：Q=XW_Q（我在找什么）、K=XW_K（我能提供什么）、V=XW_V（真要取走的内容）。Q·Kᵀ 两两打分，除以 √d_k 防数值过大，softmax 归一成权重后对 V 加权求和。
· 因果掩码：给「未来位置」的打分强行置 −∞（softmax 后即 0）——生成式模型不许偷看后文，训练与推理同款规则。
· 多头：把 d 拆成 h 份（8B: h=32，每头 d_h=128），各头在自己的子空间独立做上式、各学各的关系类型（指代、语法、位置…），结果拼接后过输出投影 W_O。

分叉 · KV 头配置
Multi-Head：每个 Q 头配独享的 K、V 头（h_kv = h_q = 32）。表达力满配，但推理时 KV 缓存最肥（Ⅲ平面详算）。原版设计，大模型已少用。
Grouped-Query：多组 Q 头共享少量 KV 头（8B: h_q=32, h_kv=8，即 4 个 Q 头共用一套 KV）。KV 缓存直接 ÷4，质量几乎不掉。Llama-3、Qwen 等当今标配——架构决策被推理成本倒逼的典型案例。
Multi-Query：极端版，全部 Q 头共用 1 套 KV（h_kv=1）。缓存最省、质量有可感损失，被 GQA 取代为主流折中。
Multi-head Latent Attention：不存 K、V 本身，存一个低秩压缩「潜向量」，用时再展开——缓存比 GQA 再小数倍。DeepSeek-V2/V3 的招牌创新，前沿方向。

⚠ 复杂度 O(T²)：打分矩阵 [B,h,T,T] 随长度平方增长——「长上下文为什么贵」的数学根源。工程补丁 FlashAttention 不改数学，只改显存访问顺序（不再落盘整个 T×T 矩阵），是「同一公式、不同工程」的好例子。

▶MoE：把 FFN 复数化MIXTURE OF EXPERTS · 🔬 LABrouter: [T,d] → top-k of E 个专家

Dense 与 MoE 的分岔点精确地在这：MoE 不动注意力，只把每层那一个 FFN 换成 E 个并联「专家」+ 一个路由器。每个 token 到来，路由器（本身是个小线性层）打分选 top-k 个专家处理，其余专家沉睡——参数总量巨大、单 token 激活量小。

▶Prefill 与 Decode 两阶段PREFILL / DECODE · 🔬 LABprefill: [T] 并行 · decode: [1] × 循环

一次请求天然分两段，性格迥异：

  • Prefill：把整段提示词一次性并行过全部 N 层（打满算力，算力瓶颈），同时为每层存下全部位置的 K、V——这就是首字延迟（TTFT）的主要来源。
  • Decode：此后每生成一个 token，只前向这一个新位置（T=1），但要读取此前全部缓存——计算量很小、搬运量巨大（显存带宽瓶颈）。吐字速度（TPS）由带宽决定。

「AI 回答前顿一下、然后匀速吐字」的完整技术解释即此。两个瓶颈不同，也解释了为什么推理优化是独立于训练的一门工程。

诚实标注（R5）：接受规则是精确实现：抽 x∼q，以 min(1, p(x)/q(x)) 接受；拒绝则从 norm(max(0, p−q)) 重抽——这正是论文里的规则，也是「分布等价」的来源。自查实验：把相似度拖到最左（草稿=胡猜），接受率暴跌（加速失效）但输出仍死死贴住目标分布——慢，但不错。分布本身为教学构造的玩具分布（真分布需真模型）。

      ▶扩散模型DIFFUSION · 🔬 LAB纯噪声 → 逐步去噪 → 图像
      

        
图像生成的心脏，与 LLM 的「猜下一词」完全不同的游戏：训练时给真图逐步加噪直到面目全非，让网络学会「从带噪图预测所加的噪声」；生成时从纯噪声出发，反复「预测噪声并减掉一点」，几十步后图像从雾中浮现。

训练时有上千档噪声强度；采样靠更聪明的求解器只需 20–50 步；再经蒸馏可压到 1–4 步——「实时出图」的来源。

文字怎么进来指挥？▼


    

      ▶条件与引导CONDITIONING · CFG · 🔬 LAB提示词 → 文本向量 → 注入每步去噪
      

        
提示词经文本编码器（CLIP/T5）变成向量，在每一步去噪时注入——相当于每步都问一遍「文字要什么」。听话程度另有旋钮：CFG（无分类器引导）同时算「有提示」与「无提示」两版预测，朝差值方向外推：

        最终预测 = 无条件预测 + s · (条件预测 − 无条件预测)
s（guidance scale）: 低 → 自由发挥；高 → 死板服从、画面僵硬（常用 5–8）
        
分叉 · 注入方式
          
          
        

        
文字向量作为 K/V、图像块作为 Q 做注意力——「图的每一块去看该看的字」。SD1.x–SDXL 的方式。

        
文与图 token 拼进同一序列、双向互看（SD3/Flux）：提示词遵从度显著提升——「AI 不听话」很大程度是文本理解带宽问题，加宽了就好些。

        
采样器、步数、种子（seed）——同一提示词千人千图的全部随机性来源；固定种子即可复现，取证场景值得知道。


        

          
🔬 实验室 · 引导强度的几何G3 级

          
CFG 公式的原样演算：○ = 无提示时模型想画的，● = 有提示时模型想画的，★ = 最终采用点。拖 s，看 ★ 沿着两点连线移动——s 大于 1 时它冲到了 ● 的外面，这就是「外推」。

          

          

            
★ = ○ + s·(● − ○)，逐点实算。s=0 自由发挥；s=1 恰好是条件预测；常用 5–8（已在外推区）；拉满看「过冲」——过度听话的画面为什么显得死板生硬。

          
诚实标注（R5）：公式与几何为精确实算（真实空间是数万维，此处取二维投影，线性外推的几何完全同构）。理解了「常用值就在外推区」这件事，也就理解了 CFG 的品性：它不是「更懂你」，是把「有提示与没提示的差异」放大——差异里有你要的语义，也有伪影。

      ▶为什么是 GPUWHY GPU · 🔬 LAB数千小核并行 · Tensor Core
      

        
LLM 的计算原子是矩阵乘法——Ⅱ 平面每个模块拆到底都是它。矩阵乘法的性格：数量海量、彼此独立、可以同时算。这正好长成 GPU 的形状：数千个简单核心齐步走（CPU 反之：少数复杂核心 + 分支预测，擅长「走一步看一步」的串行逻辑）。现代 AI 算力的主体更来自 Tensor Core：把「小块矩阵乘加」直接做成一条硬件指令，一拍完成一小块。

        
量感锚点（H100，量级取整）：BF16 算力约 10¹⁵ FLOPS。纸面推算：8B 模型 decode 一个 token 约需 2×80亿 ≈ 1.6×10¹⁰ FLOPs，理论上每秒可出数万 token——实际单请求只有百级。差出两个数量级的原因，是下一格的事。

        
分叉 · 芯片路线
          
          
          
        

        
通用并行处理器 + 成熟软件生态（CUDA 的护城河比芯片本身更深）。训练与推理的绝对主流。

        
为矩阵乘法特化的专用芯片（Google TPU、各家推理加速器）：能效比更高、通用性和生态更窄。云厂商自用为主，推理侧竞争正酣。

        
仅适合小模型或低频推理。价值在于反衬：同一个模型，CPU 上慢一到两个数量级——「AI 的一切都押在并行上」。

      ▶存储层级与内存墙MEMORY HIERARCHY · 🔬 LABSRAM → HBM → 主机内存 → 盘
      

        
核心事实：数据从来不住在计算发生的地方，要一级级搬过来。层级每往下一级，容量大十到千倍、速度慢约一个数量级（A100 量级例：片上 SRAM 约 19 TB/s 但只有 ~20MB；HBM 约 2 TB/s、几十 GB；主机内存百 GB/s 级；硬盘更慢）。

        
HBM（高带宽显存）是把 DRAM 芯片立体堆叠、经硅中介层千针直连处理器——「把仓库盖到工厂隔壁，再修一条千车道的路」。即便如此，算力的增速长期高于带宽的增速，芯片越来越多的时间花在等数据上：这就是「内存墙」。能耗账同样在搬运侧——从 HBM 搬一个字节的能耗，远高于对它做一次乘加。

        
收账（Ⅱ 平面伏笔）：FlashAttention 的全部秘密 = 精心安排计算顺序，让注意力的 T×T 中间矩阵始终待在 SRAM 里、不落 HBM。不改数学，只改「货物动线」。


        

          
🔬 实验室 · 亲自等一次数据G3 级

相对时延为量级示意（周期数因架构而异）。演出经过对数压缩：若按线性真实比例，寄存器 0.03 秒对应的 SSD 取数要让你等约 2.5 小时。

          
诚实标注（R5）：各层级「相对周期数」取业界通用量级（寄存器 1 / 片上 SRAM ~10 / HBM ~300 / 主机内存 ~3 千 / NVMe SSD ~30 万），精确数字因芯片而异。体感结论是真的：算力在等数据，等待的量级差是「墙」——也是能耗账的主体（搬运一字节 ≫ 算一次乘加）。

        

      

    

    
两个速度，一个问题：谁先到极限 ▼


    

      ▶屋顶线模型ROOFLINE MODEL · 🔬 LAB算术强度 = FLOPs / 每字节搬运
      

        
本平面的灵魂，一个问题定生死：每从显存搬 1 字节，你能拿它算几次？（这个比值叫算术强度。）机器自己也有一个平衡点 = 峰值算力 ÷ 带宽（H100 约 300 FLOPs/字节量级）。你的任务强度高于平衡点 → 卡算力（「平顶区」，芯片喂饱了）；低于 → 卡带宽（「斜坡区」，芯片在等数据）。

        decode（单请求）: 每个权重字节搬来只用一次 ≈ 1 FLOP/B ≪ 300 → 深陷斜坡区
   吐字上限 ≈ 带宽 ÷ 权重体积 = 3.35 TB/s ÷ 16 GB (8B@fp16) ≈ 200 token/s
   ——上一模块「差两个数量级」之谜，至此结案

prefill / 训练（大批量）: 同一块权重同时服务成百上千个 token
   → 强度 ×百千倍 → 跃上平顶区，算力瓶颈
        
一把钥匙开全部锁——蓝图里散落的谜团在此收束：为什么批处理能暴涨吞吐（复用权重抬强度，Ⅲ）；为什么量化「又省又快」（字节减半，斜坡区直接提速一倍，Ⅲ）；为什么 GQA/MLA 值钱（KV 搬运量变小，Ⅱ→Ⅲ）；为什么投机解码是免费午餐（把逐字 decode 改造成并行验收 = 抬强度，Ⅲ）；为什么 Prefill 快 Decode 慢（一个平顶一个斜坡，Ⅲ）。

        
诚实标注：屋顶线是刻意简化的模型（未计通信、调度、算子差异），但作为白板级思维工具，从业者真的天天用它。

      ▶数字格式NUMBER FORMATS · 🔬 LABFP32(4B) → BF16(2B) → FP8(1B) → INT4
      

        
每个参数用几位二进制存，是一根绳上的四件事：精度、显存、带宽、能耗。位数减半 ≈ 搬运减半 ≈ 斜坡区速度翻倍（接屋顶线）——所以整个行业在系统性地「用精度换速度」。

        
分叉 · 训练精度
          
          
          
        

        
砍掉 FP32 的尾数精度、保留它的指数位范围：数值表示粗一点，但极大极小值不溢出——训练稳定性的关键。当今混合精度训练的主流选择。

        
1 字节训练，Hopper 代（H100）起有硬件支持。DeepSeek-V3 大规模 FP8 训练是公开先例——「硬件代际决定训法」的实证：同样的钱买新一代卡，等于多买一倍带宽。

        
与 BF16 同为 2 字节但指数位窄，训练易溢出，需要损失缩放等补丁——被 BF16 取代的主因。

        
推理侧的 INT8/INT4 量化已在 Ⅲ 平面详述；此处补硬件视角：能不能用某个格式，先看芯片支不支持（A100 无 FP8）——「模型怎么训、怎么跑」有时是采购合同问题。


        

          
🔬 实验室 · 一个数塞进三种格式G3 级

诚实标注（R5）：各格式按其真实位分配（BF16: 8 位指数 7 位尾数；FP16: 5+10；FP8 取 e4m3 变体: 4+3）做最近可表示值的实算，溢出即判 ∞。自查两端：把数值拖到 66000——FP16 爆表（上限 65504）而 BF16 云淡风轻（量程同 FP32）；拖到 0.0001——BF16 只剩个位数的有效精度而 FP16 尚可。BF16 赢在量程、输在精度——训练宁要「接得住」不要「算得细」，这就是它成为训练主流的全部理由。
