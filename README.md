# AI Atlas · 看见 AI 如何工作

以技术为主线的交互式 AI 地图：理解工程机制、工业工具与模型谱系，并在关键环节补充法律与合规观察。

[在线访问](https://slientvoice.github.io/ai-atlas/) · [建设进度](https://slientvoice.github.io/ai-atlas/progress.html) · [版本记录](CHANGELOG.md)

当前发布版本 **v0.36 · 2026-10-26**。首批核对入门九站与蓝图十个高频模块的核心表述，增加来源、教学边界和纠错入口；建设覆盖与人工审校分开计数。谱系仍为 v5，工业现场仍为 v2。

- **首页全景**：七个技术平面的系统关系图、可切换的原创模型剖面，以及工程蓝图、工业现场、模型谱系三个大入口。
- **工程蓝图**：七平面、45 模块与 45 个交互实验，逐层解释计算、训练、模型、推理和系统。v0.36 修正分词、嵌入、注意力、门控、生成与应用边界；10/45 个模块的核心表述已对照来源，人工审校待完成。
- **工业现场**：六工位与开发工作台共 30 个条目、44 个官方来源。现场 v2，盘点基准日 2026-09-18。
- **模型门派谱系**：11 个家族、6 个比较维度、44 个官方来源链接。谱系 v5，盘点基准日 2026-10-26；更新 DeepSeek 1017、Kimi K3.1 Pro 与 Meta 开放权重，区分已发布和计划发布。Meta 托管 Spark 1.3 访问状态仍待复核。
- **索引地图与入门旅程**：七层 28 个基础节点，以及跟随一句请求理解全链路的叙事入口。
- **统一导航**：各页常驻后退、前进、返回首页和页面目录；站内链接在当前标签页打开，直接访问子页面也能回首页。

法律与合规专题将围绕数据与训练、模型与许可、应用与部署逐步建设。现有挂点是学习草稿，仍需审校；实验与图示分别标明真算法、教学简化和示意数据的边界。

## 开发与维护

站点发布物仍为纯静态 HTML/CSS/JS，无后端。首页使用 React + Vite，源码已随仓库保存；其余内容页直接维护 HTML。

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run check:links
npm run check:reviews
python3 -m http.server 8767 --bind 127.0.0.1
```

构建会更新根目录 `index.html`、首页散列资源，并同步静态页导航。请一起提交源码与构建产物。
