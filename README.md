# AI Atlas · 人工智能技术地图集

以技术为主线的交互式 AI 地图：理解工程机制、工业工具与模型谱系，并在关键环节补充法律与合规观察。

[在线访问](https://slientvoice.github.io/ai-atlas/) · [建设进度](https://slientvoice.github.io/ai-atlas/progress.html) · [版本记录](CHANGELOG.md)

站点主线版本 **v0.37 · 2026-11-20**。入门九站与蓝图核心表述可展开查看来源、适用条件和纠错入口。两份技术活页各自维护，本轮更新于 **2026-11-19**。

- **首页地图册**通过阅读地形图和分册目录进入工程蓝图、工业现场及模型谱系；系统全景支持七平面选择与五步模型剖面。
- **工程蓝图**：七平面、45 模块与 45 个交互实验，逐层解释计算、训练、模型、推理和系统。v0.36 修正分词、嵌入、注意力、门控、生成与应用边界，相关表述可展开查看资料出处与教学边界。
- **工业现场**：六工位与开发工作台共 30 个条目、50 个条目来源链接。现场 v3，盘点基准日 2026-11-19。补充推理压测、Agent 部署边界、评测与观测。
- **模型门派谱系**：11 个家族、6 个比较维度、51 个官方来源链接。谱系 v6，盘点基准日 2026-11-19。更新代表型号、托管入口与开放权重条款。
- **索引地图与入门旅程**：七层 28 个基础节点，以及跟随一句请求理解全链路的叙事入口。
- **统一导航**：各页常驻后退、前进、返回首页和页面目录；站内链接在当前标签页打开，直接访问子页面也能回首页。

法律与合规专题将围绕数据与训练、模型与许可、应用与部署逐步建设。现有挂点提供学习观察，具体适用需结合主体与业务场景判断；实验与图示分别标明真算法、教学简化和示意数据的边界。

## 开发与维护

站点发布物仍为纯静态 HTML/CSS/JS，无后端。首页使用 React + Vite，源码已随仓库保存；其余内容页直接维护 HTML。

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run check:links
npm run check:reviews
python3 -m http.server 8767 --bind 127.0.0.1
```

构建会更新根目录 `index.html`、首页散列资源，并同步静态页导航。请一起提交源码与构建产物。
